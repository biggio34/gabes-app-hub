How this works

The bot adds tabs to your Chrome — the one where you are already signed into Facebook and Google. It does not open a second browser and it does not ask you to log in again.

  1. Keep Social Sync running (double-click start.command if this page can’t load).
  2. Click Use my Chrome — Facebook opens in a new tab in your current Chrome.
  3. Read the latest post, edit the draft if you want, then publish. Google Business also opens as a new tab.
  4. One Chrome setting is required: View → Developer → Allow JavaScript from Apple Events.

The bot only talks to Chrome on this Mac. Leave the Social Sync terminal window open while you use it.
